The first update since 1.0 is all about making shared spaces feel right. Shared data now stays current in the background and refreshes the moment you ask for it, and it’s finally easy to step away from a group you’re no longer part of. Along the way we cleared up a few confusing names and fixed a batch of annoyances in shared groups.

- A manual refresh for shared spaces — pull down on the shared screen and Coconut reaches out to the group and brings in the very latest expenses
- Shared spaces now sync automatically when you open the app, so the latest changes from everyone else are already there before you start
- "Category" is now simply "budget" on the transactions screen, matching what these things actually are
- Income is now "one-off income" — a name that says exactly what it is: a one-time addition to what you have available this month
- You can leave a shared space whenever you want, with one tap in the group menu — the group is handed over to the remaining members
- Shared expenses can be deleted straight from their edit screen
- The shared screen now only lists groups you’re actually a member of — no more ghosts of spaces you were removed from
- The "who paid" selector on a shared expense now reliably highlights the person you picked
- Every member’s expenses appear in a shared group now, not only the ones you added yourself
- Personal transactions now mirror shared expenses correctly — when a shared amount changes, your own budget always keeps up
